Privacy policy

This is a privately self-hosted instance of {{ APP_NAME }}, an inventory, profit and bookkeeping tool used by a single seller for their own eBay store.

  • Data is obtained from eBay only through the seller's own authorization (OAuth) and is used only to manage that seller's own listings, sales and bookkeeping.
  • Data is stored on infrastructure controlled by the seller and is not sold, shared or transferred to third parties.
  • Buyer information is limited to what is needed for bookkeeping (order IDs, amounts, and shipping city/state/country). Buyer usernames are not stored unless the seller enables it.
  • When eBay notifies this application that a user has requested deletion of their account (Marketplace Account Deletion), any stored personal data for that user is removed.

This application uses the eBay API but is not endorsed or certified by eBay, Inc.
