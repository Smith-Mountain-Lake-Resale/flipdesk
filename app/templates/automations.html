How end & relist works

Good-'Til-Cancelled fixed-price listings renew every 30 days. Shortly before renewal FlipDesk ends the listing and immediately relists it (Trading API EndFixedPriceItem → RelistFixedPriceItem), giving a new item ID and fresh start date. If repricing is on, the new price is lowered by your percentage, never below the item's minimum price or your maximum total reduction. If a relist fails after the end succeeds, FlipDesk flags it and retries every run until it's back up. Per-item switches live on each item's edit page.
